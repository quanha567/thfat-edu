# Mock Exam (Tính năng Thi thử) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hoàn chỉnh tính năng Thi thử môn Hóa (Mock Exam) theo phương pháp ThFat Edu: học sinh tự do vào thi (on-demand), phòng thi tập trung có đếm ngược server-sync và bảng câu hỏi cắm cờ, tự động thu bài và chấm điểm tự động (áp dụng chuẩn thang điểm bậc thang Bộ GD&ĐT cho câu Đúng/Sai và chuẩn hóa câu Trả lời ngắn), hiển thị bảng điểm tóm tắt (không lộ đáp án chi tiết), giới hạn 1 lần thi cho mỗi đề.

**Architecture:**

- **Backend (ElysiaJS + Drizzle ORM + PostgreSQL)**: Thêm bảng `exam_attempts` và `exam_answers` trong `thfat-edu-be/src/db/schema/attempts.ts`. Tạo module `attempts` với 4 file chuẩn (`attempts.model.ts`, `attempts.service.ts`, `attempts.routes.ts`, `index.ts`) cung cấp các API: lấy danh sách đề thi kèm trạng thái của học sinh, bắt đầu bài thi (ẩn đáp án đúng), đồng bộ đáp án (auto-sync), nộp bài và kích hoạt công cụ chấm điểm tự động (Grading Engine), và lấy kết quả điểm số.
- **Frontend (Next.js 16 App Router + React 19 + Tailwind v4 + shadcn/ui)**:
  - Trang danh sách đề thi `/exams`: hiển thị thẻ đề thi với badge trạng thái ("Chưa làm", "Đang làm dở", "Đã nộp - Điểm: X").
  - Trang phòng thi `/exams/[id]/room`: Zen mode không navbar, đồng hồ đếm ngược server-sync, Question Palette với 3 trạng thái (đã làm, chưa làm, cắm cờ), các component render 4 dạng câu hỏi, dialog xác nhận nộp bài và tự động nộp bài khi hết giờ.
  - Trang điểm số `/exams/[id]/result`: hiển thị thẻ điểm tóm tắt, thời gian làm bài, số câu hoàn thành.

**Tech Stack:** Bun, ElysiaJS, Drizzle ORM, PostgreSQL, Next.js 16, React 19, Tailwind CSS v4, Lucide React, KaTeX/mhchem.

## Global Constraints

- `type` over `interface` (never use `interface` unless explicit declaration merging is needed).
- No `any` or `!` (always use `unknown` with narrowing, no non-null assertions).
- Max 3 parameters per function (use typed options object for >3).
- Guard clauses with early returns (max nesting depth $\le 3$).
- Function exports: `export function functionName()`.
- Generic types prefixed with `T` (e.g. `TItem`, `TAttempt`).
- Backend responses: flat data return, errors formatted as RFC 7807 Problem Details.
- Frontend: Max 200 lines per component/page, custom hooks in `features/exams/hooks/use-*.ts`.
